# Santiago Paulin — Portfolio

Personal portfolio site, deployed with **GitHub Pages**.

🔗 **Live site:** [santipaulin97-sudo.github.io/santipaulin97.github.io](https://santipaulin97-sudo.github.io/santipaulin97.github.io/)

## 📋 Contents

- Introduction and bio
- Work experience (Mercado Libre, PFS Global, Accenture, Dilcor)
- Tech stack
- Languages
- Selected projects (data, ML, automation with n8n)
- Floating contact widget (WhatsApp / Calendly)
- Direct CV download (PDF)

## 🛠️ Stack

- **HTML5 + CSS3** (glassmorphism design, no UI frameworks)
- **Vanilla JavaScript** — background canvas animation, typewriter effect, contact widget
- **Google Fonts** (Inter, Fira Code)
- **Font Awesome** for icons
- Hosting: **GitHub Pages**

## 🚀 Running locally

No build step or dependencies required. Just:

```bash
git clone https://github.com/santipaulin97-sudo/santipaulin97.github.io.git
cd santipaulin97.github.io
```

Then open `index.html` directly in your browser, or serve it with any static server, e.g.:

```bash
python -m http.server 8000
```

## ✏️ Updating the site

The project auto-deploys via GitHub Pages on every push to `main`. Changes to `index.html` go live within a few minutes.
